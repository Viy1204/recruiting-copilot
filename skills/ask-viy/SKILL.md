# Ask Viy —— 这套工具怎么用

你不需要记住任何 skill 的名字。跟 AI 说人话（"我想看看这个岗位好不好招"），它自己会找到对应流程。这张图给你看全貌，也给 AI 当路标。

被问到时：先看用户处在下面哪个位置，把对应的流程名和入口告诉他，再帮他直接开工。设计理念的完整版在仓库的 `docs/DESIGN.md`，用户想深究"为什么这么设计"时带他去读。

## 主线：从零到每天

绝大多数时候，你走的是这条线：

1. **建工作区**（`recruit-init`，只做一次）
   说"帮我初始化招聘工作区"。AI 检查该装的工具、建好文件夹、放好模板。
   已经有工作区了就跳过；重跑也不怕，它只补缺的，不覆盖你的数据。

2. **梳理岗位标准**（`recruit-grill`，每个岗位做一次）
   说"帮我梳理 XX 岗位"。AI 一次一个问题地问你，把"要个厉害的"逼成一条条能执行的标准，
   写进 CONTEXT.md（你的招聘标准手册）。半小时到一小时，别糊弄——你随口答的每一句，
   都会变成它之后每天筛掉几十个人的依据。

3. **每天跑流水线**（`recruit-daily`，天天用）
   说"处理今天的招聘"。查未读 → 按你的标准搜人初筛 → 经你确认后打招呼 → 记台账 → 出日报。
   这就是日常的全部。

## 岔路：什么时候离开主线

- **某个岗心里没底 / 老板问市场行情 / 招了很久没起色**
  → 做一次市场盘点（`market-talent-mapping`）。说"帮我盘一下 XX 岗的市场"。
  它会把两个平台的真实人才数据拉下来做统计和深挖，告诉你：这岗市场上有多少人、
  薪资什么水位、目标公司的人能不能挖、你的门槛卡得合不合理，附一份能直接执行的名单。
  和每日流水线的区别：流水线是每天的增量动作，盘点是一次性的深度调研。

- **寻了几轮，来的全是错的人**
  → 大概率标准歪了。带着台账数据回去重新梳理（`recruit-grill`），重点过硬门槛和命脉两块。

- **猎头推了简历 / 有人内推 / 候选人直接把简历发给你**
  → 简历评估（`resume-review`）。把文件丢给 AI 说"帮我看看这几份简历"。
  用的是和每日流水线同一套标准，评完自动进同一本台账；"约面"级的还会建好面试档案。
  想回忆某个人当时的评价，问"XX 的评级是啥"就行。

- **新开了岗位**
  → 先梳理（`recruit-grill`），再进每日流水线。没梳理过的岗位，流水线会拒绝开工。

## 三个日常习惯

1. **一天一个新会话**；梳理岗位也是一岗一个会话。AI 的对话越长判断越钝，
   而你的数据都在文件里，新会话什么都不丢。
2. **打招呼授权只管当天**。你说"合适的直接打"，它今天放开手、打了谁逐个报，明天要重新授权。
3. **所有数据就在你的工作文件夹里**：标准是 CONTEXT.md，候选人是 02-sourcing 里的台账，
   日报在 runtime/reports。备份文件夹 = 备份一切。

## 常见问题

- **没有飞书？** 不影响。日报自动落成本地文档。
- **换了 AI 工具？** 不影响。用新工具打开同一个文件夹，一切照旧。
- **AI 会不会替我拒人？** 永远不会。"不合适"这个按钮它碰不了，它只能记在台账里等你拍板。
- **想改标准？** 直接说"XX 岗的年龄线改一下"之类，AI 会更新 CONTEXT.md 并记一条带日期的决策。
- **AI 干活的依据是什么？** 只有你文件夹里的 CONTEXT.md 和对内笔记。它说的标准和文件不一致时，以文件为准，让它重读。
