# 报告结构模板

产出共用同一内容骨架（md 必出；飞书 / HTML 可选）。语言平实分析师口吻。

## 骨架

```
# <方向>市场人才盘点与招聘打法（<日期>）

一句话说明目的 + 术语约定（命脉/临近城市/tier）+ 数据来源与局限（强观察 vs 信号、抽样非普查）。

## 一、全局观察与结论摘要
- N 条市场观察，每条：一句结论 + 证据 + 可信度标注（强 / 信号）
- 结论摘要（可直接执行）：本周可推进的人、渠道换法、需老板拍板的取舍
- 可推进候选一览（跨岗，优先级 + 姓名 + 城市 + 一句为什么）

## 二、分岗盘点（每岗一节）
### <岗位名>
- 分布数据：年龄/年限/薪资中位/本科率/目标公司命中（几个关键数字）
- 市场观察：一段，带证据，点明该岗结构性特征
- 可推进名单（表）：候选 | 公司 | 城市 | 年龄 | 薪资 | 命脉判断(深挖) | 强/中评级
- 招聘动作：推进谁+搜什么词/走哪渠道+门槛/薪资调不调+卡在哪

## 三、预算与门槛取舍（给老板的决策点）
薪资带宽是否够、年龄/学历要不要为命脉破例、办公地坐班 vs relocate 折中——每条给建议

## 四、渠道方法论
Boss 人才库全国搜（主力）/ 猎聘（看分布）/ 猎头（命脉级补充）/ 判断纪律（开简历看主体、警惕短任期贴金与方向漂移）

## 附：可推进候选汇总 + 数据文件路径 + 局限声明
```

## 写作要点

- **观察分层**：`<结论>（强）：<数据/实例支撑>` 或 `<结论>（信号）：<单例，待验>`。别把单个简历当市场规律。
- **结论=动作**：不要停在"这岗靠猎头"这种方向判断，要落到"〔某候选〕（〔城市·公司〕）优先推进，用〔命脉证据〕终验"。
- **可推进名单**分"强/中"，"强"标可直招/临近城市，附深挖到的命脉证据。
- **诚实**：刷不出的人、样本小、渠道噪声、打码重排局限，都写进附注。
- **去口号词**：富矿/顶配/王炸这类词一律换成平实描述。

## 飞书版要点（可选，有 lark-cli 才出）
- 内容写成文件走 `lark-cli docs +create --content @<cwd相对路径> --as user`。
- callout 放一句话结论/关键洞察；表格放名单与分布；有序列表放动作清单。
- 守对外红线（敏感信息与自家品牌名不进；打码名保持打码）。

## HTML 版要点（可选）
- 编辑部/分析师严肃风：暖白纸底 + 墨色 + 一个强调色；标题衬线 + 正文黑体；避紫粉渐变、避 emoji 当图标。
- 粘性岗位跳转导航；每岗=数据 stat chips + 候选卡片（tier 徽章）；顶部"可推进候选" board。
- 数据条用纯 CSS。写完在浏览器打开核验渲染无报错。
