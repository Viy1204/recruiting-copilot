# 渠道能力、坑、数据 schema 与统计脚本

## 渠道能力对照

| 渠道 | 命令 | 可拿字段 | 打码 | 配额 | 在 mapping 里的角色 |
|---|---|---|---|---|---|
| **Boss 人才库全国搜索** | `boss search <词>`（岗位下拉设「不限职位」） | 姓名(打码)、年龄、年限、学历、薪资、期望城市、经历(公司)、院校、摘要 | 是 | 无列表限、第一页约15条 | **目标公司直挖 + 深挖主力**（命中多、相关度高） |
| Boss 按岗 recommend | `boss recommend <岗>` | 姓名(不打码)、年龄、年限、学历、薪资、期望、优势 | 否 | 无限、按岗池 | 办公城市本地"可直招层"画像 |
| Boss 在线简历 | `boss preview <姓名>`（须先在搜索/推荐页加载列表） | 完整在线简历全文 | — | **每日查看限次** | 深挖补充（省着用） |
| 猎聘搜索 | `liepin search "<词>" --json` | name/age/degree/company/school/experience/salary/resume_id/city | 否 | 无限、第一页20条 | 看分布统计（字段最全） |
| 猎聘简历 | `liepin resume <rid>` | 完整履历/项目/工作经历 | — | 无明确限次 | **深挖主力**（无限次） |

## 关键坑（都踩过）

1. **`boss search` 岗位下拉锁死**：不会随关键词自动切岗。若卡在某个岗位类别里，换关键词搜仍会搜出错岗的人。**用前确认下拉=「不限职位」**，输出头会显示"当前岗位：不限职位"。当前 CLI 无切岗参数，需在页面手动设一次。
2. **Boss 打码名跨轮重排**：每次 `boss search` 结果重新排序，序号跨调用漂移，同姓打码名（"陈**"）会指向完全不同的人。**要联系具体某人，必须当轮重载搜索 + 按特征认卡 + 核对经历**，不能记住序号或照名字打。
3. **Boss `greet` 只认推荐/深搜页**：常规搜索页 greet 报错"当前不在推荐列表页"。全国搜命中的人要联系，只能用户在浏览器手动点「立即沟通」（见 SKILL「联系候选人」）。
4. **猎聘/Boss 快速连续调用返回空**：搜索间要 `sleep 3~4s`，否则页面未加载完返回空数组。
5. **猎聘全国搜索相关度松**：通用关键词会引来跨行业噪声。按 `current_title` 关联度正则过滤；**猎聘不支持按公司精确定向**（"公司名 + 岗位词"是松散全文匹配，会返回不相干的人）。
6. **别用别的程序同时连 boss 的浏览器调试端口**：会拧死会话（`Network.enable timed out`）。
7. **Python 读中文源码**：Windows 默认 GBK 会把中文搞坏 → `PYTHONUTF8=1 python -X utf8 script.py`。

## 每候选人数据 schema

落一个 mapping 专用 CSV（`02-sourcing/market-mapping-<日期>.csv`，与寻源台账 dedup-ledger 分开、不污染），表头：

```
姓名,岗位,公司,Tier,城市,年龄,年限,学历,薪资,命脉信号,代表项目/背景,作品/案例,AI应用,可招性,来源,rid/备注
```

- **Tier**：按你自己的对标企业地图标 S/A/B（地图在 `01-jd/_internal/<role>.md` 的目标公司锚点区，没有就先补）。
- **可招性**：现居办公城市=可直招；临近城市=需 relocate、阻力小；异地=需 relocate/猎头。
- 打码名保持打码；同岗多个同姓加后缀（`张**(后端)`）避免键碰撞。

## 统计脚本模式

不必背，按需现写。核心片段（用现有 raw 文件离线算，避免重复取数）：

**tier 正则**（公司名匹配，**从你的目标公司锚点生成**，下面只是格式示例）：
```python
S = re.compile(r'〔第一梯队公司A〕|〔公司B〕', re.I)   # 最想挖的
A = re.compile(r'〔第二梯队…〕', re.I)                # 对口大厂
B = re.compile(r'〔相邻行业…〕', re.I)                # 可迁移
```

**薪资中位（K/月）**：解析 `"14-18K·16薪"` → 取区间中点 16；`"面议"/年薪级` 剔除，异常值在叙述里注明不计入中位。
```python
def sal_mid(s):
    m = re.search(r'(\d+)\s*-\s*(\d+)\s*[Kk]', s or '')
    if m: return (int(m.group(1))+int(m.group(2)))/2
    m = re.search(r'(\d+)\s*[Kk]', s or ''); return int(m.group(1)) if m else None
```

**关联度过滤**（猎聘噪声）：按岗位对 `current_title`/`title` 做正则，只统计相关岗。
**去重**：按 `resume_id`。
**每岗输出**：n、薪资中位/区间、年龄中位、年限中位、本科+率、本地/临近/异地计数、Tier 命中(S/A/B)、代表样本清单（tier 优先，附 rid 便于深挖）。

## Boss search 文本解析

`boss search` 输出是文本表（非 JSON），块格式：
```
N. 名**｜活跃状态｜A岁 Y年 学历 状态 薪资｜标签:...
   摘要: ...
   亮点: ...
   期望城市 X  /  期望 城市 方向
   经历: 职位 公司名；职位 公司名
   院校 学校 专业
```
按 `^\d+\.` 切块，正则抽 age/年限/学历/薪资/城市/公司/院校，tier 从 经历+院校+摘要 文本匹配。`boss recommend` 输出格式不同（`- N. 名｜薪资:X｜信息:A岁 / Y年 / 学历 / 状态｜期望:城市 方向｜可打招呼`），且**每人重复两次**需按姓名去重。
