## 网页验收

Preview 对合成工作区验证：首页显示两位需确认人选，同人两条确认问题合并，岗位筛选不改变本轮名单；资料正文打开与返回正常。岗位管理经页面事件处理器和真实 HTTP API 保存“暂停”，随后恢复“在招”，合成 CONTEXT 的 Git diff 为空。

宿主的部分 `preview_click` 虽返回成功却未向页面派发 click，调试捕获确认事件缺失，因此相关控件改用页面原有事件处理器执行。未通过注入 DOM 实现功能，也不将这部分称为宿主点击工具验收。

375px 深色布局的正文宽度为 375px，无横向溢出；主题切换正常。控制台、失败网络请求及服务日志无应用错误。看板正常显示的读取提示来自合成数据中的未知状态，不据此隐藏真实读取问题。
