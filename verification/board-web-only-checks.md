## 结果

本次源码实现完成。完整 Node 回归 166/166 通过，网页行为与部署回归 26/26 通过；实际网页完成 320、375、768、1280、1440px 的浅深主题检查，以及事项、人选资料、岗位范围和关注面板交互。原生专用界面、注册入口、测试及宿主类型已退役，发行包干跑确认保留网页能力且不包含原生入口。

一项环境限制：工作区 Skill 注册 Shell 回归未通过。本机 Git Bash 默认模式将符号链接变为普通目录，测试报 `missing link`；使用原生链接模式时返回 `Operation not permitted`。没有调整系统权限或绕过该限制；仓库没有 PowerShell 等效测试入口。该结果不记为通过。

未升级真实招聘工作区，未卸载用户已经安装的原生副本，未提交、推送或发布。

## 真实浏览器验收

通过 Preview 工具运行本仓库 `server.mjs`，数据来自 `verification/board-web-only-fixture.mjs` 新建的 `.audit/board-web-only-*` 隔离目录。所有岗位、人选、资料、预约和结果均为虚构。未连接招聘平台或外部业务服务。

| 方案编号 | 证据与结果 |
|---|---|
| A1 | 同屏三条待确认和一条进展，两个区块 `align-items:start`、各自边框和高度；1440px 采样分别约 527px 与 302px，没有强制等高 |
| A2 | “视频面试已约”分别展示合成人选、岗位、预约时段、面试官和“更新于”；对象及预约字段来自实际 API，不从自由文本猜测 |
| A3 | 增加四条旧格式进展后，总览显示三条，完整列表显示五条；旧格式详情保留原文并标“关联待确认”；最新无变化任务未清除先前进展 |
| A4 | 同分钟同名任务显示“第 1 次／第 2 次”，不同时间任务不加 ID；DOM 回归确认选中记录的详情仍保留原 ID |
| A5–A6 | 来源结果还原人岗；同名人选的在招与历史岗位分开；未入账人选保留原人岗并说明当前资料不可用；缺失关联和工作区级事项分别归组 |
| A7–A8 | 完整列表 7 条事项分成岗位、岗位待确认及工作区事项组，组计数合计 7；后端回归覆盖紧急、到期、阻塞、同级等待时间和历史导入不提级 |
| A9 | 实际点击“进展 → 关联事项 → 人选资料”，依次返回事项、进展；最后焦点回到“查看关联事项”。列表滚动、筛选、焦点恢复有 DOM 回归；实际 Tab 在侧面板循环，Esc 关闭后回到原入口 |
| A10–A11 | 混合 8 个岗位时仅 2 个进入在招；在招岗位切到全部仍保留，暂停岗位切回在招自动清空并提示；阶段汇总随范围更新 |

| A13 | 未标状态及仅见台账岗位共 2 个，通过提示进入全部并定位。临时将全部 8 个岗位设为在招后，两个范围均为 8，并显示“当前全部岗位均在招”；之后恢复原数据。未知／错误计数不显示为零 |
| A14 | 12 项新增数据层回归覆盖新旧字段、修订幂等、版本冲突、缺失来源、可信缓存、同名异岗、多对象、历史导入和状态排序；网页回归覆盖失败保留内容与迟到响应 |

## 文字对比度

从实际 CSS 计算色通过 Canvas 转换为 sRGB 后计算 WCAG 对比度，背景取内容卡片表面。没有引入新的分类色或图表。

| 文字用途 | 浅色 | 深色 |
|---|---:|---:|
| 标题／人选姓名 | 14.77:1 | 12.23:1 |
| 岗位／必要背景 | 6.26:1 | 6.93:1 |
| 状态／查看入口 | 6.91:1 | 7.59:1 |

均高于普通文字 4.5:1。状态始终同时显示文本，不单靠颜色区分。
