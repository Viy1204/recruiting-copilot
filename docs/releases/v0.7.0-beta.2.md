# v0.7.0-beta.2 测试版（2026-10-26）

本次更新招聘看板的确认名单与阅读布局，并固定包含城市搜索修复的 Boss CLI 测试版本。GitHub Release 为预发布，正式 Latest 仍是 `v0.6.6`。

## 本次变化

- 首页优先显示当前任务“本轮需确认”的人选、需要拍板的问题、资料与依据；同一人选的多条确认记录合并展示，人数按姓名和原岗位去重。
- 执行记录、任务历史和候选阶段默认折叠，按需展开；切换岗位筛选不改变当前任务的确认名单。原生面板采用相同的信息顺序，继续使用宿主组件。
- 调整浅色、深色、窄栏和移动布局的文字对比度与间距。候选资料返回、任务跟随、历史固定与岗位草稿继续保留阅读上下文。
- 依赖安装器固定 Boss fork `0.8.5-beta.1`，Git 标签为 `copilot-beta-20261026`。该版本修复隐藏页面的 `search --city` 挂起，并加强搜索结果、页面快照与候选定位校验，增加显式 `boss reload`。

看板只操作本地记录。打招呼、拒绝、邀约等对外动作仍按工作区确认规则执行；本版不增加自动外联权限。

## 固定版本安装

完整宿主安装、已有工作区迁移与回退规则沿用 [beta.1 说明](v0.7.0-beta.1.md)，其中源码标签改用 `v0.7.0-beta.2`。新试用目录执行：

```bash
git clone --branch v0.7.0-beta.2 --depth 1 https://github.com/Viy1204/recruiting-copilot.git recruiting-copilot-beta
```

Claude Code 可按原有 marketplace 来源更新插件；单次会话加载时指向这份固定源码。主插件与可选 `recruiting-board` 原生插件均为 `0.7.0-beta.2`。原生插件只从一个来源加载，避免与工作区发现入口重复。

DeepSeek Harness 使用：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.7.0-beta.2
```

源码 ZIP 包含主插件与命令；npm TGZ 用于 DSH／脚本，不替代 Claude marketplace 源码。仍需 Node.js ≥22 与支持 `AbortSignal.timeout`／`AbortSignal.any` 的现代浏览器。

## Boss CLI 依赖

本版默认安装来源：

```text
git+https://github.com/Viy1204/boss-cli.git#copilot-beta-20261026
```

安装器会克隆该固定标签、构建并打包后全局安装，保留 `BOSS_CLI_SOURCE` 自定义覆盖。此测试标签单独随内测版交付，不更新 npm 的稳定 `latest`。固定标签对应提交 `64e356875f89943fc5b7451a6088a6eb8b889f31`，已核对远端标签。

仅需更新依赖时，在固定源码目录执行：

```bash
sh skills/recruit-init/scripts/install-dependencies.sh
```

脚本也会检查或安装猎聘 CLI。已有源码开发软链无需反复全局安装，先确认软链目标确实是本版修复；不要用 `boss update` 将测试软链换回 npm 稳定版。

城市筛选修复保留完全匹配，不会在失败时悄悄改成全国搜索。`boss reload` 仅刷新当前已登录主壳并作废旧搜索快照，随后需重新执行原只读查询；不自动重做打招呼或发送操作。

## 从 beta.1 升级工作区

升级插件不会自动替换已有工作区 `skills/`。先备份工具副本和定制说明，再同步 `skills/recruit-board/`；如同时使用项目级 `.agents/skills`、`.claude/skills` 或 `.qoder/skills` 独立副本，也应同步相应工具文件。保留原生插件的单一加载来源。

本版另需更新工作区 `recruit-init/scripts/install-dependencies.sh`，并将初始化说明中的默认 Boss 来源改成上述固定标签。仅更换这些工具文件与对应说明，不覆盖 `CONTEXT.md`、候选台账、JD、档案、定时预算或业务 `runtime/`。工作区内的定制招聘规则保持原样。

重新打开宿主会话后加载新插件；已打开的网页刷新即可读取新的静态资源。

## 验证与边界

网页已用合成工作区验证确认名单、资料跳转与返回、浅深主题和 375px 布局。匹配的 Claude Desktop 2.1.299 引擎完成原生交互测试、严格插件校验与类型检查。最终测试、发行包核验和 Boss 固定提交见 [发布验收](../../verification/release-v0.7.0-beta.2-checks.md)。

本次不把原生模拟测试等同于所有宿主实机验收；Codex App、WorkBuddy 与一周生产试用仍需各自验证。回退时恢复原固定版本及工具备份，保留试用期间的业务记录。
