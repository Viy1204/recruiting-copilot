# v0.8.2 正式版

v0.8.2 更新招聘工作台布局，让待关注事项、近期进展和人选名单更易浏览。人选按最近可核实的实际进展倒序排列，详情统一到可逐层返回的侧面板。主包和主插件版本均为 `0.8.2`。

## 本次交付

- 总览突出待关注事项与近期进展，压缩搜索、任务状态和工具入口；保留原版 RC、暖色浅深主题、总览／岗位与人选／执行记录三视图和本机布局偏好。
- 人选名单、阶段、岗位范围和姓名搜索先按全量活动索引排序，再每批显示 20 条。姓名加原岗位区分身份，同名异岗各自排序，无可靠时间排在后面。
- 排序使用有效档案事件的实际发生时间或处理收据的实际记录时间，标明来源；只有日期的记录按日显示。不把未来预约、文件修改时间、任务后续更新或任意备注日期当成实际进展。已明确撤回的误记不参与当前进展与排序。
- 人选、事项和进展共用详情面板，返回时保留筛选、滚动和焦点。后续更新保护正在阅读的内容；时间来源异常时保留可信旧值并在人选页提示。
- 包含 v0.8.1 后已合入主线的[结果、资料与档案进展修复](https://github.com/Viy1204/recruiting-copilot/pull/55)：逐人结果保留原人岗关联，资料分类和原件下载更清楚，近期进展读取有效面试档案事件，并修正跨平台绝对路径识别。

## 固定版本安装

需要 Node.js ≥22 和现代浏览器。

```bash
git clone --branch v0.8.2 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后，按 [README](../../README.md#开始使用) 配置所需 CLI 和主插件。DeepSeek Harness 使用：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.2
```

GitHub Release 提供源码 ZIP、TGZ 和 SHA256 校验和。源码 ZIP 包含主插件 `.claude-plugin/`、commands 与完整源码；TGZ 供 DSH 与脚本使用，不替代完整插件源码。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

1. 暂停本工作区的并行写入，按既有机制取得维护锁，备份工具副本与本地定制规则。
2. 从固定版本同步 `skills/recruit-board/` 工具文件，并核对项目级 Skill 实际指向的副本。相对 v0.8.1，本版还包含上述结果、资料和档案进展修复，不能只替换网页文件。已有本地脚本约定应逐项合并，避免覆盖。
3. 保留招聘标准、候选台账、JD、简历、面试档案、事项与轮次历史，以及定时授权、时段和预算；比较业务文件升级前后的校验和。不使用初始化模板覆盖已有工作区。
4. 重启由用户或宿主管理的网页服务，通过 `connect.mjs` 核对工作区标识和 `workspace-overview,run-highlights` 能力，再打开返回的完整链接并刷新页面。本机关注与布局偏好继续保留。
5. 在岗位名单或姓名搜索中核对最近实际进展、日期精度、资料打开与详情返回。旧档案没有可靠发生时间时保留“无可核实时间”，不为排序补造日期。

本版没有持久化数据格式迁移，活动索引在既有读取中生成。源码更新不会自动升级工作区副本，也不会迁移或停用其他来源的旧安装。先前原生入口的退役步骤仍见[宿主说明](../../skills/recruit-board/references/hosts.md#原生入口退役与升级)。

## 回退与兼容边界

停止新版服务，恢复升级前工具备份，并回到对应主插件或源码版本。保留全部业务记录和决定历史；回到更早版本前仍需核对已有结构化记录的兼容性，见 [v0.8.1 回退说明](v0.8.1.md#回退与兼容边界)。

看板不连接招聘平台，不增加联系、拒绝、邀约或通知授权。候选台账保持只读；岗位管理仍仅在用户保存时更新本地岗位表并备份。

## 验证

本地完整 Node 回归 **238/238** 通过，覆盖全量排序后分页、同名异岗、日期精度、未来时间排除、撤回误记、来源异常、阅读保护和详情关闭竞态。浏览器已验证 320/375/768/1440px、浅深主题与关键交互；采样关键文字最低对比度 **5.90:1**。真实工作区已只读核对首批 20 条、前 40 条与独立全量排序一致，用户检查界面和排序后批准发布。
