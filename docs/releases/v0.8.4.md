# v0.8.4 正式版

v0.8.4 将默认 BOSS CLI 固定为 `@viyzhu/boss-cli-fork@0.8.9`，合入 `v0.8.3` 以来招聘工作台、猎聘防风控指引与验证基线的更新，并将主包与主插件版本同步设为 `0.8.4`。

## 本次交付

- **默认 BOSS CLI 升级至 0.8.9**（[PR #70](https://github.com/Viy1204/recruiting-copilot/pull/70)）。在 `skills/recruit-init/scripts/install-dependencies.sh` 与 `skills/recruit-init/SKILL.md` 将默认安装源设为 `@viyzhu/boss-cli-fork@0.8.9`。该系列在 `0.8.8` 带来 BOSS 收藏（`boss favorite`）与预览输出修复的基础上，在 `0.8.9` 适配了搜索池新版详情面板的账号权益按钮；`BOSS_CLI_SOURCE` 仍可显式覆盖安装来源。
- **招聘工作台响应式分拣与交互升级**（[PR #62](https://github.com/Viy1204/recruiting-copilot/pull/62)、[PR #63](https://github.com/Viy1204/recruiting-copilot/pull/63)、[PR #64](https://github.com/Viy1204/recruiting-copilot/pull/64)、[PR #65](https://github.com/Viy1204/recruiting-copilot/pull/65)、[PR #67](https://github.com/Viy1204/recruiting-copilot/pull/67)）。
  - 上线响应式 B+C 分拣工作台与三栏人选档案视图，支持宽屏分栏与窄屏内联展开。
  - 新增 `POST /api/decisions` 与 `web-decisions` 健康检查能力，在本地暂存人工拍板决定，并通过 `DECISION_OP_FORBIDDEN` 拦截 `register`、`import`、`evidence`、`action`、`close` 与 `invalidate` 操作，设计边界记录于 [ADR 0006](../adr/0006-responsive-triage-and-staged-decisions.md)。
  - 新增 `Mod+K` 模糊快速跳转面板（多词召回与 `mark` 高亮）以及人选表格单 Tab 停靠点与方向键漫游焦点。
  - 引入本地托管的 `ui-sdk-core` 基础行为并增加路径安全与 CSP 校验，同时修复被动切到全部人选视图时冻结总览刷新的问题。
  - 同步各 Agent 入口的 `recruit-board` 软链，移除 DSH 中已废弃的 `set-mode` 接口与无头切换死代码，并清理过程产物。
- **猎聘防风控节奏与软限流停手规则**（[PR #68](https://github.com/Viy1204/recruiting-copilot/pull/68)）。在 `skills/recruit-daily/references/channels.md` 明确连续 `search` 上限与停顿、列表预筛后再调 `liepin resume` 的节奏和随机抖动，以及触发「已达到每日简历浏览上限」时的立即停手与 `liepin risk --json` 检查流程。
- **验证基线与版本同步检查**（[PR #69](https://github.com/Viy1204/recruiting-copilot/pull/69)）。同步状态机形式化验证基线并新增实时验证技能 `.claude/skills/verify-recruit-board/`；在 `tests/version-sync.test.mjs` 新增表驱动的版本同步测试，在 `npm test` 中自动校验 `package.json`、`README.md`、`skills/recruit-init/SKILL.md`、`install-dependencies.sh` 与发版说明之间的版本一致性。

## 固定版本安装

需要 Node.js ≥22、本机 Chrome 或 Edge，以及相应招聘平台账号。

```bash
git clone --branch v0.8.4 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后，运行依赖安装器。

```bash
sh skills/recruit-init/scripts/install-dependencies.sh
```

DeepSeek Harness 使用以下命令安装：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.4
```

GitHub Release 提供源码 ZIP、TGZ 与 SHA256 校验和。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

下载源码或更新主插件不会自动升级已安装的 BOSS CLI。已有工作区可按下方命令单独升级 BOSS CLI。

```bash
npm install -g @viyzhu/boss-cli-fork@0.8.9 --registry=https://registry.npmjs.org/
```

核对安装版本和命令入口。

```bash
boss version
```

```bash
boss help
```

同步工作区的 `skills/` 与 `skills/recruit-board/` 工具文件，并确认 `.agents/skills/`、`.claude/skills/`、`.qoder/skills/` 入口指向最新副本。同步时保留工作区内的业务数据，包括 `CONTEXT.md`、`02-sourcing/dedup-ledger.csv`、`01-jd/` 与 `03-interview/`，不要用初始化模板覆盖已有工作区。

## 回退与兼容边界

主插件或源码可切回 `v0.8.3`，并保留全部业务记录、本地决定历史与轮次记录。BOSS CLI 独立安装，切换主插件或源码版本不会自动回退它；手动装回旧版 CLI 会恢复旧版的面板与预览行为。

## 使用边界

本次更新不增加任何招聘平台写操作授权。网页工作台提交决定只写入本地事项记录，同步台账、更新 `CONTEXT.md` 与执行平台联系动作仍须在下一轮已授权的工作流中核实执行。BOSS 收藏、在线简历预览与猎聘检索仍受各自平台账号权益、每日额度与风控规则约束，遇异常提示或验证拦截须立即停手并由人工核验。
