# v0.8.1 正式版

v0.8.1 将招聘看板统一为各 Agent 共用的网页，补齐跨轮事项、人岗关联与进展细节，并合入[分轮批量梳理岗位要求](https://github.com/Viy1204/recruiting-copilot/pull/53)。主包和主插件版本均为 `0.8.1`。

## 本次交付

- 总览、岗位与人选、执行记录分别呈现。近期进展和待处理事项各自按内容定高，宽窄屏与浅深主题使用同一网页。
- 事项跨轮保留，决定与后续执行分开。总览展示待回答或历史待核对摘要，完整列表按岗位分组并保留状态筛选。
- 历史事项沿可靠来源恢复姓名与原岗位。无法确定的关联明确提示，不凭自由文本串联同名人选或推断处理结果。
- 新事项和进展可记录结构化对象与事件细节；预约时段、面试官和更新时间分开显示。旧记录继续可读。
- 进展、事项和人选资料支持逐层返回，保留阅读位置与焦点。任务名称使用类型、时间和可靠对象，完整 ID 收进详情。
- “在招”只包含明确在招岗位，“全部”保留历史与未知状态，“我的关注”是独立的本机集合。未知状态有可点击提示，切换范围时清除范围外岗位选择。
- 移除独立原生面板插件、注册模块和专用验证。主招聘插件、共享模型、脚本及各工作流接入保留。
- 岗位梳理先读已有资料，按依赖分轮批量提问；每题附建议，已确认结论不重问。关键标准待定时保留草稿，不用于正式初筛。

## 固定版本安装

需要 Node.js ≥22 和现代浏览器。

```bash
git clone --branch v0.8.1 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后，按 [README](../../README.md#开始使用) 配置所需 CLI 和主插件。DeepSeek Harness 使用：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.1
```

GitHub Release 提供源码 ZIP、TGZ 和 SHA256 校验和。源码 ZIP 包含主插件 `.claude-plugin/`、commands 与完整源码；TGZ 供 DSH 与脚本使用。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

1. 先暂停本工作区的并行写入，按既有机制取得维护锁，备份工具文件和定制规则。
2. 同步 `skills/recruit-board/` 中的网页、模型、脚本、公共类型及说明；确认项目级 Skill 入口实际指向的副本全部更新，避免混用版本。
3. 同步六个执行工作流的看板接入与结构化记录说明。已有定时授权、时段、预算、共用锁、邮箱触发规则和本地专属约定必须保留。岗位梳理可按 PR 的新访谈规则更新，不能覆盖工作区已确认的岗位标准。
4. 对工作区中已核实的旧原生专用入口先备份，再移除或停用。独立安装的原生插件按[原生退役说明](../../skills/recruit-board/references/hosts.md#原生入口退役与升级)核对来源和范围后处理。仓库或主插件更新不会自动卸载其他安装位置。
5. 重启由用户或宿主管理的网页服务，通过 connect 核对工作区标识和 `workspace-overview,run-highlights` 能力，再刷新网页。已有历史任务和本机关注偏好继续保留。
6. 比较升级前后的业务文件校验和，确认 `CONTEXT.md`、候选台账、JD、面试档案、简历、轮次与事项历史、预算和定时规则未被工具升级改写。

本次不要求批量迁移旧数据。旧事项通过已有来源补充展示信息；旧记录缺少可靠来源时保留“关联待确认”。不要用初始化模板覆盖真实工作区，也不要为了显示新字段回写旧业务事实。

## 回退与兼容边界

停止新版服务，恢复升级前工具备份，并回到对应主插件或源码版本。新版新增的 context/details 字段仍应保留；旧版程序可能不认识新字段，因此回退前核对运行时记录是否已由新版写入，不能靠删字段或丢弃决定历史强行降级。

只读旧文件、按现有来源恢复展示，不会自动批准、关闭或执行事项。看板不连接招聘平台，不新增联系、拒绝、邀约或飞书通知授权。

实现与隔离验收见[单网页验收记录](../../verification/board-web-only-checks.md)，整合发布验证见[发布检查](../../verification/release-v0.8.1-checks.md)。
