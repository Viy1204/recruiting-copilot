# v0.8.3 正式版

v0.8.3 将依赖安装器的 BOSS 维护包固定到 `@viyzhu/boss-cli-fork@0.8.7`，接入未读漏报与在线简历预览修复。主包和主插件版本均为 `0.8.3`。

## 本次交付

- 接入 [BOSS CLI v0.8.7](https://github.com/Viy1204/boss-cli/releases/tag/v0.8.7)：`list --unread` 识别「新」角标并等待角标与列表稳定，`chat --index --unread` 使用相同的判定规则。
- 同版修复 `preview` 在隐藏旧简历 iframe 位于可见新简历之前时误报未打开的问题。
- 初始化说明、固定版本下载入口和默认依赖安装回归同步更新。`BOSS_CLI_SOURCE` 仍可显式覆盖安装来源。
- 对应 [未读漏报 issue](https://github.com/Viy1204/recruiting-copilot/issues/52) 和已合入的 [BOSS CLI 修复 PR](https://github.com/Viy1204/boss-cli/pull/12)。

## 固定版本安装

需要 Node.js ≥22、本机 Chrome 或 Edge，以及相应招聘平台账号。

```bash
git clone --branch v0.8.3 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后，运行依赖安装器。

```bash
sh skills/recruit-init/scripts/install-dependencies.sh
```

DeepSeek Harness 使用：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.3
```

GitHub Release 提供源码 ZIP、TGZ 与 SHA256 校验和。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

下载源码或更新主插件不会自动升级已安装的 BOSS CLI。已有用户直接更新平台工具：

```bash
npm install -g @viyzhu/boss-cli-fork@0.8.7
```

核对安装版本和命令入口。

```bash
boss version
```

```bash
boss help
```

若工作区保留了旧版依赖安装器或初始化 Skill，按既有工具同步方式更新这些工具文件，避免下次安装降回旧版本。保留现有 `BOSS_CLI_SOURCE` 定制时，须自行核对所指定来源包含本次修复。

本版不修改工作台逻辑，不迁移数据格式，也不要求重新初始化工作区。保留招聘标准、候选台账、JD、简历、档案、事项与轮次历史。更早版本的工作台升级仍按 [v0.8.2 升级说明](v0.8.2.md#升级已有工作区) 执行。

## 回退与兼容边界

主插件或源码可切回 `v0.8.2`，保留所有业务记录。BOSS CLI 独立安装，切换主插件版本不会自动回退它；手动安装旧版 CLI 会重新引入本次修复前的问题。

## 使用边界

本次更新不增加任何招聘平台操作授权。未读判定仍受页面的有限观察窗口限制；窗口结束后才开始的渲染可能需要重新读取。在线简历仍受平台每日查看额度约束，OCR 仍需显式开启。
