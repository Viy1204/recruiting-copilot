# v0.8.5 正式版

v0.8.5 将默认 BOSS CLI 升级为 `@viyzhu/boss-cli-fork@0.8.10`，合入禁止宿主浏览器扩展替代平台 CLI 的操作约束与后台前台策略说明，并将主包与主插件版本同步设为 `0.8.5`。

## 本次交付

- **默认 BOSS CLI 升级至 0.8.10**（[boss-cli PR #19](https://github.com/Viy1204/boss-cli/pull/19)）。有头模式下常规 BOSS 命令（含 `list`、`search`、`recommend`、`greet` 等）默认不再主动前置浏览器窗口，避免窗口在后台未最小化时反复打断其他应用。`BOSS_BROWSER_NO_FOREGROUND` 未设置、空值、真值或未识别值均保持不前置；显式设 `false`（`0` / `no` / `n`）才恢复前置请求，并继续尊重已最小化窗口。`boss login` 保留显式唤起，在线简历截图（`preview` / `action resume`）仍保留必要的可见渲染处理。
- **禁止用宿主浏览器工具替代平台 CLI**（[PR #74](https://github.com/Viy1204/recruiting-copilot/pull/74)）。在 `skills/recruit-daily/SKILL.md`、`skills/recruit-daily/references/channels.md`、`skills/market-talent-mapping/references/channels-and-analysis.md`、`skills/recruit-init/templates/AGENTS.md` 与 `README.md` 明确要求 BOSS 与猎聘的寻源、查未读和读简历统一走 `boss` / `liepin` CLI，不得静默降级到 Cindy `user-browser` 等宿主自带浏览器扩展，避免同时丢失前台控制、反检测守卫与 `<canvas>` 空白壳校验。
- **后台运行参数说明完善**（[PR #74](https://github.com/Viy1204/recruiting-copilot/pull/74)）。在 `channels.md` 与 `README.md` 区分 `boss-cli` `0.8.10` 默认不前置与旧版 `0.7.2` 到 `0.8.9` 显式加 `BOSS_BROWSER_NO_FOREGROUND=true` 的用法，并保留不启用无头模式的红线。

## 固定版本安装

需要 Node.js ≥22、本机 Chrome 或 Edge，以及相应招聘平台账号。

```bash
git clone --branch v0.8.5 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后，运行依赖安装器。

```bash
sh skills/recruit-init/scripts/install-dependencies.sh
```

DeepSeek Harness 使用以下命令安装：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.5
```

GitHub Release 提供源码 ZIP、TGZ 与 SHA256 校验和。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

下载源码或更新主插件不会自动升级已安装的 BOSS CLI。已有工作区可按下方命令单独升级 BOSS CLI。

```bash
npm install -g @viyzhu/boss-cli-fork@0.8.10 --registry=https://registry.npmjs.org/
```

核对安装版本和命令入口。

```bash
boss version
```

```bash
boss help
```

同步工作区的 `skills/` 与 `skills/recruit-board/` 工具文件，并确认 `.agents/skills/`、`.claude/skills/`、`.qoder/skills/` 入口指向最新副本。同步时保留工作区内的业务数据，包括 `CONTEXT.md`、`02-sourcing/dedup-ledger.csv`、`01-jd/` 与 `03-interview/`，不要用初始化模板覆盖已有工作区。

## 回退与兼容边界

主插件或源码可切回 `v0.8.4`，并保留全部业务记录、本地决定历史与轮次记录。BOSS CLI 独立安装，切换主插件或源码版本不会自动回退它；如需回退旧版前台激活行为，可在运行命令时显式设置 `BOSS_BROWSER_NO_FOREGROUND=false`。

## 使用边界

本次更新不增加任何招聘平台写操作授权，也继续禁止使用无头模式（`RECRUIT_BROWSER_HIDDEN=true` / `BOSS_BROWSER_HEADLESS=true`）。平台寻源与读简历必须通过 `boss` / `liepin` CLI 执行；若 CLI 不可用或报错，先排查修复而不静默改用宿主浏览器扩展。

## 验证

`npm test` 完整 Node 回归通过（含 `tests/version-sync.test.mjs` 的版本与入口一致性校验），无失败或跳过。依赖安装器回归 `tests/install-dependencies.test.sh` 与工作区 Skill 注册回归 `tests/register-workspace-skills.test.sh` 均通过，确认默认安装源为 `@viyzhu/boss-cli-fork@0.8.10`。
