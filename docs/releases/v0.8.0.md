# v0.8.0 正式版

v0.8.0 将招聘进展网页整理为“招聘工作台”。Workspace 导航、全局姓名搜索和宽窄布局让你在浏览器或宿主侧栏中核对同一份招聘记录。主包、主插件和可选原生插件统一为 `0.8.0`；原生面板继续使用原有宿主组件。

## 本次交付

- 顶部按完整或部分姓名搜索全部岗位、阶段和历史岗位。搜索结果替换岗位区，清空后恢复原岗位与阶段；保留同名不同原岗位的记录。
- 宽屏新增 Workspace 同页导航、关注岗位入口和工作区信息。正文默认三列，中等宽度两列，窄侧栏单列；按实际容器宽度适配。
- 明确零确认时压缩为摘要；有事项时展示人选，未知和读取异常仍保留原因。确认事项只属于所选任务。
- 调整布局时临时切成单列，支持拖动、上下移动、键盘确认取消及恢复默认。旧工作区布局顺序继续保留。
- 搜索、资料返回、历史任务、关注偏好和浅深主题与新结构兼容。开发预览可切换宽屏和窄栏，正式页自动适配。
- README 和使用说明更新为当前页面截图，全部使用合成演示数据。

## 固定版本安装

需要 Node.js ≥22 与现代浏览器。BOSS 与猎聘 CLI 的依赖来源沿用 v0.7.0，不因工作台升级变更招聘平台授权。

```bash
git clone --branch v0.8.0 --depth 1 https://github.com/Viy1204/recruiting-copilot.git
```

进入源码目录后安装依赖：

```bash
sh skills/recruit-init/scripts/install-dependencies.sh
```

Claude Code 按 [README 插件入口](../../README.md#claude-code-插件入口) 添加该固定源码目录。已有 marketplace 先核对来源，再按原来源更新并重新打开会话，避免同时加载不同副本。

DeepSeek Harness 使用：

```bash
dsh plugin --profile web add git+https://github.com/Viy1204/recruiting-copilot.git#v0.8.0
```

源码 ZIP 包含主插件 `.claude-plugin/` 和 `commands/`；TGZ 供 DSH 和脚本使用，不替代完整 Claude 插件源码。本版本不向 npm 发布 recruiting-copilot。

## 升级已有工作区

先备份工作区工具文件和定制规则，再同步本版本 `skills/recruit-board/`。源码或插件升级不会自动替换先前复制到工作区的工具文件。

保留 `CONTEXT.md`、候选台账、JD、面试档案、定时预算及业务 `runtime/`。不要用初始化模板覆盖它们。项目级 Skill 入口继续指向同一份 `skills/`，注册冲突按[已有工作区升级说明](v0.7.0.md#升级已有工作区)处理。

本次布局沿用 `recruiting-board:layout:v1:<workspaceKey>` 及原模块标识，确认区承接原“招聘助手”的排序位置；搜索固定在正文结构顶部，不参与排序。关注与岗位选择仍按工作区保存。损坏或不可用存储会明确提示并降级。

同步后刷新网页；若服务仍加载旧的首页参数校验，重启用户或宿主管理的看板服务。默认入口和[手动启动命令](../recruit-board.md#手动打开看板)不变，保留 connect 返回的完整工作区标识。

## 回退与兼容边界

停止本版服务，恢复升级前工具文件备份或 v0.7.0，再重新打开对应会话和网页。本次没有迁移业务文件或改变排序存储版本。回退不会撤销之前单独保存过的岗位状态；需要恢复岗位表时先核对其原文备份。

网页仍只读取本地候选台账和资料；岗位状态仅在明确保存时写入本地岗位表，不改变招聘平台职位。不新增联系、拒绝或邀约授权。

合成与真实工作区的验证及边界见[工作台验收](../../verification/workspace-layout-checks.md)和[日常安装验证](../../verification/workspace-layout-installed-checks.md)。实体手机、所有宿主与完整辅助技术未逐一实测。可选原生面板没有采用这次网页布局；其运行能力继续取决于实际宿主版本。
