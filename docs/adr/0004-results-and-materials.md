# ADR 0004：人选结果统一呈现与资料原件入口

日期：2026-11-04

状态：已接受。用户已确认[处理结果、岗位归并与资料入口方案](../plans/recruit-board-results-and-materials.md)，并明确以打开或下载原件为准，无需看板内预览。

## 背景

同一评价分别作为重点和处理收据展示，造成重复阅读；名单按钮只展开屏下列表，缺少可见反馈。历史岗位名称只在全部范围出现却无法管理。资料收取允许的格式比看板读取范围更广，外部缓存路径和非结构化档案字段也使已存在资料不可达。

## 决策

1. 执行记录按本轮原人岗身份合并重点与完整结果。默认最新结论，处理经过与证据展开查看。归组不删除原事件或改写历史；没有可靠关联的内容另行保留，不凭自由文本猜配。
2. 处理名单与确认入口定位各自目标。确认数量使用当前关联事项，按项计数；已确认、暂缓与旧收据进入历史区。已知为零、未接入与读取失败分别表达。
3. 岗位管理增加待归并名称与已有别名编辑，目标限当前正式岗位。原台账名称和身份保持不变，在招仍只取正式状态。保存带版本、锁、备份与原子替换，不能覆盖更新后的配置。
4. 候选资料提供原件打开或下载入口。PDF、PNG/JPG 与文本可独立打开；DOC/DOCX/RTF 强制下载原件，不增加转换服务。工作区路径和实际文件类型仍校验，不通过网页开放任意磁盘文件。
5. 资料映射支持用户确认与更正，工作区资料选择限已有资料目录。已确认外部文件由本地导入工具复制到工作区，保留来源和内容校验值，原件保留，重跑去重。资料缺失、关联歧义和读取错误明确区分，候选介绍不冒充简历。
6. 后续收取与建档同步归档和资料关联。历史补齐优先推进中人选，再覆盖其余台账；来源查找和补取遵循原业务授权，不因此联系候选人。

## 与既有决策的关系

沿用 ADR 0001 的任务事实与独立事项分离，沿用 ADR 0002 的三视图、详情和阅读位置保护，沿用 ADR 0003 的网页界面、可靠对象关联与严格在招范围。本次补充执行记录的去重呈现及本地管理能力；经用户确认，验证完成后同时升级真实工作区。

## 验收

同人双源只占一个条目、同名异岗不误并、历史与未知记录不丢失；按钮实际点击后目标可见；已关闭事项不再计为当前待回答。别名保存后筛选与管理一致。资料关联可持久更正，外部归档可重复执行，常见原件可打开或下载。虚构数据回归和网页验收通过后备份升级真实工作区，并记录未能补齐的资料。
