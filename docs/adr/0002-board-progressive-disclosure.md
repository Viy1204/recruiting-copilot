# ADR 0002：招聘看板按任务组织视图，详情独立呈现

日期：2026-11-04

状态：按用户“参考优秀 GitHub 看板，变得简洁易用”的反馈实施。保留 ADR 0001 的跨轮持久化与决定／执行语义，只调整呈现。后续 [ADR 0003](0003-web-only-board.md) 沿用三个视图与渐进展开，补充结构化对象、岗位分组及逐层返回；下文原生引擎验收已由网页验收替代，真实工作区部署不属于本次单网页改动范围。

## 证据与问题

用户的窄栏和桌面截图显示：相同任务在两个位置展示；零数量分组、读取时间及阅读提示占据首页；历史事项展开后拉长整页，其他栏目留白；所有模块并排导致桌面主内容仍很窄。

参考的公开一手资料：

- [Plane](https://github.com/makeplane/plane) 与 [Display options](https://docs.plane.so/core-concepts/issues/display-options)：列表卡片可选择显示属性、空分组可不显示；[Work items](https://docs.plane.so/core-concepts/issues/overview) 将列表与点击后详情分开。
- [Planka](https://github.com/plankanban/planka)：[CardModal](https://github.com/plankanban/planka/blob/master/client/src/components/cards/CardModal/CardModal.jsx) 独立打开卡片；[Communication](https://github.com/plankanban/planka/blob/master/client/src/components/cards/CardModal/Communication.jsx) 分开评论和活动。借鉴主从交互，不复制代码和样式。
- [Homepage](https://github.com/gethomepage/homepage) 与 [Settings](https://gethomepage.dev/configs/settings/)：用 tabs、initiallyCollapsed 组织模块；statusStyle:dot 缩短状态。只借鉴分层与紧凑显示，不隐藏故障。

## 决策

1. **三个真实视图**：总览、岗位人选、执行记录。桌面侧栏和窄屏顶部使用相同导航，同一时间只显示相关内容。姓名搜索仍可快速进入人选视图，搜索/岗位/历史选择保留。保留布局排序数据和编辑能力，布局编辑只在显式打开设置时展示各模块。
2. **总览只回答当下问题**：一个紧凑的最近任务条，最多三条当前需要回答或核对的事项，以及最多三条近期重点。桌面总览使用足够宽的两栏（事项与进展），窄栏纵向。移除重复任务卡和“另有N个进行中”的首页负担；仅描述文件记录，不把旧running当作进程存活证明。
3. **事项以列表为主**：默认优先显示当前待确认；没有待确认而有历史待核对时，直接呈现“待核对”列表，而不是先看零事项空页。已暂缓、后续执行、处理历史、全部事项通过“查看全部事项”的列表面板进入；非零历史／后续可有一行简短入口。0数量不占独立卡片，未知和错误仍明确显示。
4. **独立详情**：点击事项打开详情侧面板；窄栏使用同一面板全宽，关闭返回原列表位置。详情先给问题、当前结论、必要后续动作；证据、来源和完整修订历史默认收起，避免相同决定被重复铺满首页。列表面板与详情共享一个界面，不叠多层弹窗。
5. **安静但可信的状态**：正常读取时间归数据详情，阅读保持继续有效但只有出现真实更新时提示。暂无近期重点用一行说明并保留执行记录入口，不堆空卡片。显示“当前没有待回答事项；另有N条历史待核对”避免把历史未知说成全部完成。
6. **保留原行为**：事项与后续动作不删除、合并或自动关闭；不新增批准/拒绝按钮，不改变聊天决策入口、来源保护、实时更新、工作区隔离、失败缓存和授权边界。历史超过7天仍可查。

## 交互验收

- 用户截图所示状态（open0、history10、closed4）进入总览即可看到3条待核对摘要，全部可达；不出现多排0数量按钮。
- 详情再长也不增加首页文档高度；关闭后回到原列表及焦点，Esc可退出，键盘焦点在网页面板内。
- 首屏只显示一份任务状态；点击任务进入执行记录，不同时铺三列模块。
- 切换总览／岗位人选／执行记录不丢查询、所选岗位、展开数量和历史轮次。姓名查询只存在页面内存，不写 URL、持久偏好或远程请求。
- 详情阅读时新更新提示，不抢位置；仅点击空白/选筛选不产生常驻阅读提示卡。
- 0、未接入、读取失败分别显示；故障不能为了简洁被隐藏。
- 320／375／1280px、浅深主题、实际点击及原生引擎测试通过。
- 虚构工作区验收后，只备份部署本轮界面文件到真实工作区；不改事项、台账或原任务状态。
